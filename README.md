# ScorpiLibria — приложения

Публичные сборки приложений [ScorpiLibria](https://scorpilibria-frontend.vercel.app/apps):

- **Android (телефоны, планшеты, Android TV)** — файл `ScorpiLibria.apk` в разделе
  [Releases](https://github.com/Scorpioom/scorpilibria-apps/releases/latest).
  Прямая ссылка на последнюю версию: `scorpilibria-frontend.vercel.app/apk`.
- **Samsung Smart TV (Tizen, 2017+)** — модуль для [TizenBrew](https://github.com/reisxd/TizenBrew):
  в TizenBrew нажмите зелёную кнопку → «Менеджер модулей» → «Добавить модуль с GitHub» →
  введите `Scorpioom/scorpilibria-apps`.

Подробные инструкции — на странице «Приложения» сайта.
